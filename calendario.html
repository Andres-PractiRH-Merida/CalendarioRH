    🔑 Acceso para publicar (se configura una sola vez)

    Para guardar directo en el calendario se necesita un token de GitHub con permiso de escritura solo en este repositorio. Se guarda únicamente en este dispositivo. Crear token (Repository access: solo este repo · Permissions: Contents → Read and write).

    ¿Sin token? y pégalo en el archivo eventos.json de GitHub, dentro de la lista «eventos».

    Lista de invitados

    Al guardar, la lista del evento queda igual a lo que aparece en este cuadro. Para agregar más gente, pega debajo de lo que ya está.

    ¿Cómo se usa el calendario?

    1. Toca un díaLos días con puntos de color tienen eventos. Se abre la agenda de ese día.
    2. Revisa el detalleVerás horario, lugar y mapa. Si el evento tiene el botón «Ver lista de participantes», tócalo para desplegarla.
    3. Agrega un eventoUsa el botón rojo «+ Agregar evento» de la esquina inferior. Solo necesitas título y fecha.
    4. Filtra y buscaCon «Filtros y búsqueda» encuentras eventos por nombre, categoría o modalidad.
